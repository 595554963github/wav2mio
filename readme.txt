≪概要≫
　使用 miocompress.exe 可以将 PCM 格式的 WAV 文件压缩为 MIO 格式。
　使用 mioplayer.exe 可以播放 MIO 文件。

≪压缩方法≫
　启动 miocompress.exe，将想要压缩的 WAV 文件拖放到窗口中。文件名将被添加到压缩文件列表中。
　在此状态下，设置压缩参数，然后点击“压缩开始”按钮。
　将在原始文件所在的目录中生成 MIO 文件。

≪压缩参数说明≫

【简易指定】
　为各参数设置预设值。
　进行无损压缩时，也在此处选择。

【低频权重】
　用于在量化时决定以何种精度量化低频成分。
　重视高频成分时，将该值设低。
　但若设置过小，可能会产生块噪声或导致声音本身失真。
　指定实数。

【中频权重】
　用于在量化时决定以何种精度量化中频成分。
　重视高频成分时，将该值设低。
　但若设置过小，可能会产生块噪声或导致声音本身失真。
　指定实数。
　减小【低频权重】及【中频权重】的值，会使压缩更重视高频成分，因此高频成分较多的数据的压缩率会比高频成分较少的数据低。

【量化系数】
　用于在量化时计算分配多少比特的参数。通过该参数可以大致指定压缩率。
　该参数并非基于通用单位，而是与内部参数联动，因此相当粗略。
　指定整数。
※压缩为可变比特率，因此压缩率取决于数据本身。

【B块失真对策系数】
　指定用于减轻块失真的系数。
　选择 0、1、2 中的任一值。数值越大，越能减轻失真。

【PE阈值系数】
　指定用于计算预回声对策阈值的系数。
　指定 2 以上的整数。
　数值越小，越不易产生预回声，但压缩率会变差。
　在低比特率压缩时，建议设置较大的数值。

【矩阵大小】
　指定压缩所使用的矩阵大小。
　可从 512x512、1024x1024、2048x2048 中选择。
　矩阵越大，压缩特性越好，但更容易产生预回声等问题。

【使用中侧立体声】
　勾选后，将使用中侧立体声方式压缩立体声数据。
　由于利用声道间的相关性进行压缩，因此音质优于普通立体声。
